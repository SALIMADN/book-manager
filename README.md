# book-manager
A web application for managing personal book collections.  Add books to favorites, remove them, and edit user profiles.  Built with HTML, CSS, Bootstrap, and react.js

![Open Library API](https://img.shields.io/badge/API-Open_Library-00B0D8?style=for-the-badge)

## ✨ Features
- ✅ **Real Book Data** - Fetched from Open Library API
- ✅ **Add/Remove Favorites** - Saved to Local Storage
- ✅ **User Profile** - Edit personal information
- ✅ **Responsive Design** - Works on all devices

## 🛠 Tech Stack
- **React 18** - Frontend library
- **Vite** - Build tool
- **Boutstrap CSS** - Styling
- **Open Library API** - Book data source
- **Local Storage API** - User preferences

## 📦 Quick Start

```bash
# Clone the repository

# Navigate to project
